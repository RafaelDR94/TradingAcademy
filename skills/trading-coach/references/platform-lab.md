# Platform Lab

## Objective

Use platforms to make mechanics observable. Do not let interface familiarity substitute for conceptual understanding.

## MT5 demo

Use primarily for:

- Bid/Ask;
- spread;
- lot size;
- order types;
- SL/TP;
- PnL;
- balance/equity;
- margin/free margin/margin level;
- execution mechanics.

### Before any demo order

Confirm:

- account is demo;
- connection is active;
- symbol is correct;
- lot size is intentional;
- exercise purpose is explicit.

For a mechanics exercise, do not imply that BUY or SELL is a market recommendation.

### Reading an order

Require the learner to identify:

1. symbol;
2. volume;
3. order type;
4. entry side;
5. Bid/Ask;
6. SL;
7. TP;
8. spread/cost;
9. expected effect on margin.

### Five-decimal Forex quotes

For pairs such as EUR/USD:

- 0.00010 = 1 pip;
- 0.00001 = 0.1 pip, often called a pipette;
- 10 points = 1 pip when MT5 point size is 0.00001.

Verify symbol specification if precision differs.

## TradingView

Use primarily for:

- market structure;
- top-down analysis;
- replay;
- support/resistance zones;
- pullbacks;
- breakouts;
- annotated examples;
- manual backtesting.

## Screenshot workflow

When the user provides a screenshot:

- read only what is visible;
- do not invent hidden quotes or account state;
- distinguish frozen/historical data from live data when evidence supports it;
- ask for a narrower screenshot only when a field is unreadable.

## Current broker/platform facts

For broker rules, market hours, commissions, stop-out levels, leverage limits or platform behavior that may change, verify current sources before making a factual claim.
