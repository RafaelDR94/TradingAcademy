# Trading Journal

Cada operación de replay, backtest, demo o real debe estar etiquetada por entorno.

## Campos obligatorios

- ID.
- Fecha/hora.
- Entorno.
- Activo.
- Sesión.
- Temporalidad de contexto.
- Temporalidad de entrada.
- Versión de estrategia.
- Dirección.
- Contexto.
- Setup.
- Condiciones cumplidas.
- Entrada.
- Stop.
- Objetivo.
- Riesgo en R.
- RR planeado.
- Resultado en R.
- MFE/MAE si existe.
- Captura antes/después.
- Cumplimiento de reglas.
- Regla violada.
- Emoción antes/después.
- Comentario.
- Revisión.
- Etiquetas.

## Calidad de ejecución

- A: siguió todas las reglas.
- B: desviación menor.
- C: fuera de plan o datos insuficientes.

La nota A/B/C mide disciplina, no rentabilidad.
