# Session Specification

## Propósito

Definir el contrato operativo de cada clase de Trading Academy. Una sesión no se considera completada solo porque transcurrió tiempo: debe dejar evidencia observable de aprendizaje.

## Duración objetivo

30 minutos.

La duración es una guía de diseño, no un motivo para interrumpir una clase antes de completar el ciclo de aprendizaje.

## Estructura obligatoria

### 1. Recuperación activa — 0 a 5 min

Objetivo: comprobar retención sin volver a explicar primero.

- 3 a 5 preguntas cortas de material previo.
- Variar números y contexto para evitar memorización literal.
- Registrar errores que indiquen una debilidad estructural.
- Si falla un concepto crítico de riesgo, órdenes o sizing, marcar `REINFORCEMENT`.

### 2. Concepto nuevo — 5 a 15 min

Objetivo: introducir una sola idea central.

Requisitos:

- definición precisa;
- ejemplo numérico;
- relación con conceptos ya dominados;
- error común;
- aplicación en plataforma o gráfico cuando sea pertinente.

No introducir varias ideas nuevas si una de ellas todavía no puede explicarse con palabras propias.

### 3. Práctica — 15 a 25 min

Objetivo: convertir teoría en ejecución observable.

Puede incluir:

- cálculo;
- lectura de gráfico;
- clasificación de escenario;
- configuración de MT5/TradingView;
- simulación;
- decisión basada en reglas;
- registro de journal.

La práctica debe producir evidencia verificable.

### 4. Mini examen — 25 a 28 min

- 3 preguntas nuevas.
- No revelar respuesta antes de que el alumno responda.
- Corregir inmediatamente.
- Objetivo de dominio: **80%**.
- Si el resultado es inferior o existe un error crítico, no marcar el tema como `MASTERED`.

### 5. Cierre — 28 a 30 min

Registrar:

- tema;
- resultado;
- concepto más fuerte;
- error principal;
- evidencia generada;
- siguiente objetivo;
- decisión: `ADVANCE`, `REINFORCE` o `RECOVERY TEST`.

## Definición de "clase completada"

Una clase queda `MASTERED` únicamente si:

- se realizó práctica;
- el alumno puede explicar el concepto central;
- no persiste un error crítico dependiente;
- mini examen >= 80%;
- se actualizó la documentación.

Si falta evaluación, usar `EVIDENCE PENDING`.

## Principios de enseñanza

- Una buena operación puede perder.
- Una mala operación puede ganar.
- La calidad de decisión se evalúa aparte del resultado monetario.
- No usar PnL como sustituto de disciplina.
- No introducir dinero real como incentivo.
- Las fórmulas deben mostrarse de forma explícita y legible.

## Artefactos mínimos por sesión

Cada archivo de clase debe contener:

1. Objetivos.
2. Prerrequisitos.
3. Recuperación activa.
4. Concepto.
5. Ejemplos.
6. Práctica.
7. Errores observados.
8. Mini examen y resultado.
9. Checklist.
10. Estado de dominio.
11. Siguiente paso.
