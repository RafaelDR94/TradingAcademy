# Assessment System

## Tipos de evaluacion

### Diagnostico
Establece linea base. No es aprobatorio.

### Mini examen
Tres preguntas al final de una sesion. Umbral: 80%.

### Checkpoint semanal
Composicion:
- 40% recuperacion conceptual;
- 30% aplicacion numerica o de reglas;
- 30% lectura de escenarios.

Umbral: 85%.

### Examen final
Compara contra la linea base y exige aplicacion, no solo definiciones.

## Regla de preguntas
Las preguntas se reformulan. No se considera dominio si el alumno solo recuerda el ejemplo exacto.

## Registro obligatorio
Cada evaluacion conserva:
- alcance;
- preguntas;
- respuestas;
- correccion;
- puntaje;
- errores;
- decision;
- temas a recuperar.

## Regla critica
Un resultado alto no compensa un error esencial de riesgo, apalancamiento, ordenes o position sizing.
